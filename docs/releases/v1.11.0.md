## Highlights

- **Saved Views:** save keywords, tags, folders, and media filters, then reopen a View to browse the latest matching images.
- **Uninterrupted fullscreen browsing:** background list refreshes no longer close the image preview or switch the image being viewed. Deleting the current image moves directly to the next one.
- **Fixes:** corrected LoRA/hypernetwork names in escaped prompts, image-comparison closing, and structured-output requests to OpenAI-compatible services.
- **Changelog links:** the homepage and both READMEs now link directly to the repository's `CHANGELOG.md`.

## Downloads

- **Windows:** the regular installer, alternative PyInstaller installer, and standalone CLI remain available.
- **macOS preview:** choose `aarch64-unsigned.dmg` for Apple Silicon or `x64-unsigned.dmg` for Intel. Requires macOS 14 or later. Drag the app into Applications before opening it.

### Important: macOS builds are not notarized

There is no Apple Developer ID signature or notarization. Bundled executables and Python libraries use ad-hoc signatures, which do **not** make the app trusted by Gatekeeper. macOS may block the app or its Python backend. Follow [Apple's instructions](https://support.apple.com/en-us/102445) only if you trust the official download; do not disable Gatekeeper system-wide.

macOS data and logs are stored in `~/Library/Application Support/com.zanllp.iib/`. If the window opens but the backend does not start, include the relevant entries from `iib_api_server.log` in an issue. Access to protected folders is a separate permission in System Settings.

The macOS parent watchdog now watches the desktop process itself instead of assuming Python is its direct child. This fixes an immediate backend self-exit caused by the extra launcher process in onefile packages.

The build checks the bundled backend, packaged frontend resources, database creation, image thumbnails, video covers, and shutdown. These checks do not replace testing a downloaded, quarantined installer on another Mac.
