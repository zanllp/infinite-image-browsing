## Desktop updates

If you use **v1.11.0 or earlier**, install this release manually once. Starting with v1.12.0, the Windows and macOS desktop apps can update in place.

When a newer release is available, the welcome page shows **Update to {version}** with a **new** badge. Nothing is downloaded until you click the link and confirm. After installation the app restarts. If the update fails, you can continue using the current version or download an installer from GitHub.

## Other changes

- Saved Views can be refreshed from their header. Folder navigation, grid tags, and stack lists now refresh more reliably.
- Renaming a file accepts a filename, not a path, on every platform. Copying and moving files also handle conflicts and partial failures more clearly.

## Which file should I download?

- **Windows:** use the regular x64 setup executable, or the PyInstaller variant if you prefer that build. A standalone Windows CLI is also available.
- **macOS 14 or later:** choose the Apple Silicon (`aarch64`) or Intel (`x64`) DMG and drag the app into Applications. These preview builds are ad-hoc signed, not notarized. See the [macOS installation notes](https://github.com/zanllp/infinite-image-browsing#macos-unsigned-preview) if Gatekeeper blocks the app.

The update archives, signatures, and JSON files are for the desktop updater. For a manual installation, use an installer or DMG instead.
